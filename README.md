# Web Programming DT - Backend Express & TypeScript

## Description
This project is a backend application developed as part of the web programming coursework. It implements an MVC architecture using **Express**, **TypeScript**, and a direct connection to a **PostgreSQL** database managed through SQL migration scripts (no local JSON data storage).

## Technologies Used
- **Node.js** & **Express** (Web framework)
- **TypeScript** (Static typing)
- **PostgreSQL** (Relational database)
- **node-pg-migrate** (Database migration management)
